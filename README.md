# 3D-Brain-Tumor-Segmentation-Using-Adapted-HTC-Net-Framework
. This project addresses the challenge of segmenting
brain tumors from multi-parametric MRI scans within the
BRaTS 2021 dataset. Utilizing a modified version of the
HTCNet architecture, originally designed for 2D image
analysis, I adapted the model to handle 3D medical
images by implementing 3D convolutional layers and
window-based Transformer blocks to capture spatial
hierarchies and contextual information effectively. The
model was trained using a combination of Dice loss
functions to optimize segmentation accuracy. Results
indicate that the adapted HTCNet is capable of
segmenting tumor regions. This study underscores the
possibilities and difficulties of using sophisticated deep
learning methods for medical image analysis and suggests
further investigation to improve model performance for
clinical use.
